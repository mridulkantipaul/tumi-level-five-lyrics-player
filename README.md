# tumi-level-five-lyrics-player

A minimal karaoke lyrics player that keeps timestamped LRC lyrics synced with audio playback.

## Usage

1. Open `/home/runner/work/tumi-level-five-lyrics-player/tumi-level-five-lyrics-player/index.html` in a browser.
2. Load an audio file (`.mp3`, `.wav`, etc.) using **Audio file**.
3. Load a timestamped `.lrc` lyrics file using **LRC lyrics file**.
4. Play the audio and the current lyric line will be highlighted automatically.

## LRC format example

```text
[00:00.00]Intro line
[00:10.50]First line of verse
[00:20.00]Second line of verse
```
